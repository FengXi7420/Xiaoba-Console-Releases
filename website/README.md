# 小吧控制台发布介绍页

这是小吧控制台的静态发布介绍页文件，面向更新仓库和正式发布下载页使用。

## 文件结构

```text
website/
├── index.html
├── style.css
├── animations.css
├── script.js
├── assets/
│   └── logo.png
└── README.md
```

## 设计口径

- 产品定位：面向 MSI 微星笔记本的第三方硬件控制台。
- 视觉方向：暗色硬件控制台、橙色主强调、少量青绿色状态色。
- 发布口径：闭源免费、本地运行、无遥测、提供 SHA256 校验。
- 信息结构：下载、能力、安装、安全说明、兼容性、文档支持分区展示。
- 动效原则：保留控制台扫描、仪表条呼吸、滚动显现等轻量反馈，尊重 `prefers-reduced-motion`。

## 本地预览

直接打开 `index.html` 即可预览。需要本地服务器时可以使用任意静态文件服务，例如：

```powershell
npx http-server .\website -p 8000
```

然后访问 `http://localhost:8000`。

## 发布前需要替换

- 更新仓库 Release 下载地址。
- Gitee Release 或国内对象存储镜像地址。
- 每个安装包、便携包对应的 SHA256 校验值。
- 兼容性文档、FAQ、快速开始文档的最终公开地址。

## 许可证口径

发布介绍页跟随渠道版发布口径。小吧控制台当前为闭源免费工具，不使用公开代码许可证口径；页面文案应保持“闭源免费、本地运行、无遥测、提供校验”的表达。
