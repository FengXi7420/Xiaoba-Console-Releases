# Xiaoba Console Branding Assets

This directory contains the public repository icon and social preview used by Xiaoba Console.

- `m-control-repository-icon.png`: 512x512 repository/avatar image.
- `m-control-social-preview.png`: 1280x640 social preview image.

The filenames retain the shared MControl technical identity. The user-visible product name is Xiaoba Console / 小吧控制台, and the product theme color is `#D23D1D`.
