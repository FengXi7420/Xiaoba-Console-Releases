# 小吧控制台 v1.0.2

发布日期：2026-08-10

## 本版内容

- 修复 MS-182L / Raider A18 物理 KLC `PID_1122` + ALC `PID_1161` 组合下的 Prism 固件键位布局。
- 固件 catalog、静态、逐键、Rainbow Split、Aurora、Gold Splash、Chakra、Disco、Reactive Key 统一沿用有效 `PID_205A` identity。
- 动态固件效果补齐 Scroll Lock、PgUp、PgDn（`0x47`、`0x4B`、`0x4E`）等 102 个正式 KLC assignment。
- `steelseries-fw-basic + prism` 恢复活动层、响应层、闲置层控件；Legacy FW-basic 仍保持单层。
- 修复灯效速度摘要重复显示 `/10`。
- 便携版暂不发布，本版仅提供普通安装版和 WebView2 Fixed 安装版。
