# 小吧控制台 v1.0.0

发布日期：2026-08-10

这是小吧控制台独立发行线的首个正式版本。功能基线继承 M-Control v1.3.45，公开版本从 `1.0.0` 重新开始；本次不表示硬件控制能力回退到早期 M-Control v1.0.0。

## 本版内容

- 用户可见品牌统一为“小吧控制台” / `Xiaoba Console`。
- 关于页改为淘宝、京东、闲鱼、抖音、B站、贴吧、微信七个渠道入口；微信仅显示二维码，闲鱼同时提供二维码和链接。
- 增加独立“小吧管家”下载入口，移除原作者、赞助、赞赏码和 QQ 群入口及其发布资源。
- 更新检查、下载、问题反馈和文档链接全部切换到 `FengXi7420/Xiaoba-Console-Releases`。
- 修复关于页本地化把 DOM 元素误当 CSS selector、导致初始化中断和导航失效的问题。
- 应用图标和底层硬件控制功能保持现有实现，不因换皮重画或改写。

## 安装与升级

- 安装目录、可执行文件、数据目录和 Inno AppId 继续使用共享的 MControl 技术身份，因此小吧控制台与 M-Control 不能并存，安装后会以同一产品身份替换。
- M-Control v1.1.0 及更高版本可直接运行小吧控制台安装包替换；更早的 M-Control 建议先卸载。
- 后续小吧控制台版本可从 v1.0.0 直接覆盖升级。
- 主程序和安装包当前未做 Authenticode 代码签名，Windows 可能显示 SmartScreen 或“未知发布者”。
