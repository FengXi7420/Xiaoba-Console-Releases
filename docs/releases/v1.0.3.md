# 小吧控制台 v1.0.3

发布日期：2026-08-12

本版本完成 MS-182L 动态固件灯效与 Fn 快捷键的实机闭环，并修复 Fixed WebView2 安装版的自动更新选包。

## 主要更新

- 修复 MS-182L 动态固件灯效中 `Print Screen (0x46)` 与 `Scroll Lock (0x47)` 的固件坐标相位错位；仅对目标 `PID_205A + PID_2059` 身份补偿，其他机型和实时灯效路径保持不变。
- 恢复 `Fn+F5`、`Fn+F6`、`Fn+F7`、`Fn+Right` 的 SCM 事件激活，并在睡眠恢复后重建 WMI watcher。
- 固件灯效及亮度不在电源模式切换时由软件重放，继续由 MCU 保持自身状态。
- Fixed WebView2 安装版检查更新时会继续选择 Fixed 安装包，不再下载普通安装版。
- 上述灯效、快捷键、睡眠恢复和更新路径已在 MS-182L 实机合并验证通过。
