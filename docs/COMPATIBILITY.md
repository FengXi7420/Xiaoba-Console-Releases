# 兼容性列表

本页列出已知的小吧控制台兼容性测试结果。

## 状态说明

| 图标 | 状态 | 说明 |
|------|------|------|
| ✅ | 完全支持 | 所有功能正常工作 |
| ⚠️ | 部分支持 | 主要功能可用，部分功能受限 |
| ❌ | 不支持 | 大部分功能不可用 |
| ❓ | 未测试 | 尚无用户反馈 |

## 功能模块

- **监控**：CPU/GPU 温度、频率、功耗监控
- **风扇**：风扇曲线控制、全速模式
- **性能**：性能模式切换（平衡/安静/高性能/节能）
- **GPU模式**：核显/混合/独显切换
- **电池**：充电上限设置
- **灯效**：SteelSeries 键盘灯效控制

## 影响兼容性的因素

### 1. BIOS 和 EC 固件版本

- 不同 BIOS 版本的 WMI 接口可能有差异
- EC 固件更新可能改变寄存器布局
- **建议**：使用最新 BIOS 版本（从 MSI 官网下载）

### 2. MSI 驱动状态

**必需驱动：**
- MSI ACPI WMI Provider / MSIWMIACPI2
- 通常随 MSI Center 或驱动包安装

**检查方法：**
```
设备管理器 → 系统设备 → 查找 "MSI ACPI" 相关项
```

### 3. 显卡配置

- **NVIDIA GPU**：只读监控需要 NVIDIA 驱动和可用的 NVAPI / NVML
- **AMD GPU**：部分监控功能可能受限
- **核显 Only**：GPU 模式切换不可用
- **GPU 模式能力识别**：后续需按 MSI Center 同源的 `MsiDCVarData[5]` / `0x2F` 能力位收紧，不再在能力未知时默认展示核显、混合、独显三项；详见 [GPU 模式能力识别待办](gpu-mode-capability-detection-backlog.md)。

### 4. 键盘类型

**SteelSeries 键盘**：
- 需要特定 HID 设备 PID
- 不同型号键盘协议可能不同
- 部分老机型可能不支持全部灯效

**非 SteelSeries 键盘**：
- 灯效功能不可用
- 其他功能正常

## 已知限制

### 不支持的机型

❌ **非 MSI 笔记本**
- 风扇控制、性能模式、GPU 模式切换等功能不可用
- 部分监控功能可能可用（如果有 NVIDIA 显卡）

❌ **MSI 台式机**
- 主要针对笔记本设计
- 台式机可能缺少必要的 EC 和 WMI 接口

❌ **特别老的机型（2020年前）**
- 可能缺少现代 WMI 接口
- EC 寄存器布局可能不同

### 功能限制

| 功能 | 限制条件 |
|------|----------|
| GPU 模式切换 | 需要支持 MUX 开关的机型 |
| SteelSeries 灯效 | 需要 SteelSeries 键盘 |
| 风扇校准 | 需要稳定的 RPM 读数 |

## 如何报告兼容性

如果你的机型不在列表中，欢迎反馈测试结果！

### 提供信息

请在 [GitHub Issues](https://github.com/FengXi7420/Xiaoba-Console-Releases/issues) 中提供：

1. **机型信息**
   - 完整型号（例如：Raider 18 HX A14VHG）
   - BIOS 版本
   - EC 版本（如果知道）

2. **系统信息**
   - Windows 版本
   - 已安装的 MSI 软件

3. **功能测试**
   - 哪些功能可用 ✅
   - 哪些功能不可用 ❌
   - 遇到的问题

4. **诊断报告**
   - 使用"生成诊断报告"功能
   - 附上生成的 ZIP 文件

### 标题格式

```
[兼容性反馈] 机型名称 - BIOS 版本
```

**示例：**
```
[兼容性反馈] Raider 18 HX A14VHG - BIOS 1.10
```
