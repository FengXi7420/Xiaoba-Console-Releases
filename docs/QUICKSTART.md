# 快速开始指南

欢迎使用小吧控制台！这份 5 分钟指南将帮助你快速上手。

---

## 📥 第一步：安装

### 下载

从 [GitHub Releases](https://github.com/FengXi7420/Xiaoba-Console-Releases/releases) 下载最新版本：
- **推荐**：`MControl_v<版本号>_Setup.exe`（安装包）
- 或选择：`MControl_v<版本号>_Portable.zip`（便携版，免安装；不会自动安装 PawnIO，完整硬件功能推荐使用安装版）

### 安装

1. 双击运行下载到的 `MControl_v<版本号>_Setup.exe`
2. 阅读许可协议和安装说明
3. 选择安装位置（默认：`C:\Program Files\M-Control`）
4. 等待安装完成（会自动安装依赖项）

### 首次启动

**重要：建议以管理员身份运行**

- 右键桌面快捷方式 → **以管理员身份运行**
- 或在快捷方式属性中设置为始终以管理员运行

**为什么需要管理员权限？**
- 访问硬件底层接口需要系统权限
- 控制风扇、切换性能模式等功能需要权限

---

## 🎯 第二步：查看仪表盘

启动后，你会看到 **仪表盘** 页面：

### 实时监控

仪表盘显示以下信息：

- **CPU**：温度、频率、功耗
- **GPU**：温度、频率、功耗、利用率
- **风扇**：CPU 风扇和 GPU 风扇转速
- **电池**：电量、充放电状态
- **内存**：使用率

### 查看模式切换

- 点击风扇区域可在 **RPM 模式** 和 **百分比模式** 之间切换
- RPM 模式显示实际转速（例如：3500 RPM）
- 百分比模式显示相对转速（例如：50%）

**提示**：首次使用百分比模式时，建议先进行风扇校准（见第四步）

---

## ⚡ 第三步：调整性能模式

点击左侧导航栏的 **性能** 图标：

### 四种模式

1. **平衡** ⚖️
   - 日常使用推荐
   - 性能和噪音平衡

2. **安静** 🔇
   - 办公、看视频场景
   - 降低风扇噪音
   - 性能适度降低

3. **高性能** 🚀
   - 游戏、渲染场景
   - 全力释放性能
   - 风扇转速较高

4. **节能** 🌿
   - 外出使用、延长续航
   - 降低功耗
   - 性能明显降低

### 切换方法

- 点击对应模式卡片
- 等待 1-2 秒应用生效
- 观察仪表盘数值变化

---

## 🌪️ 第四步：自定义风扇曲线（可选）

点击左侧导航栏的 **风扇控制** 图标：

### 查看当前曲线

- 默认显示当前 BIOS 设置的风扇曲线
- 横轴：温度（°C）
- 纵轴：风扇转速（RPM）

### 调整曲线

**方法 1：拖拽调整**
- 直接拖动曲线上的点
- 实时预览变化

**方法 2：表格编辑**
- 在下方表格中输入精确数值
- 每个温度点对应一个转速

### 应用设置

1. 调整完成后，点击 **应用**
2. 系统会立即应用新曲线
3. 观察仪表盘风扇转速变化

### 恢复默认

- 如果调整不满意，点击 **恢复默认**
- 会恢复到 BIOS 默认曲线

### 风扇校准（推荐）

**为什么要校准？**
- 不同机型风扇满速转速不同
- 校准后百分比显示更准确

**如何校准：**
1. 点击 **风扇校准** 按钮
2. 风扇会全速运行 30 秒
3. 程序自动采样并计算满速基准
4. 完成后自动保存

---

## 🎮 第五步：GPU 相关功能（可选）

### GPU 模式切换

点击 **GPU 模式** 页面：

- **核显模式**：仅使用集成显卡，省电
- **混合模式**：自动切换集显和独显
- **独显模式**：始终使用独立显卡，性能最佳

**注意**：切换后需要 **重启电脑** 才能生效

## 🔋 第六步：电池管理（可选）

点击 **电池** 页面：

### 充电上限设置

**建议设置：**
- **日常使用**：80%（延长电池寿命）
- **外出使用**：100%（最大续航）
- **长期插电**：60%-80%（最佳保护）

**如何设置：**
1. 拖动滑块或输入数值
2. 点击 **应用**
3. 电池充电会在达到设定值时停止

### 查看电池健康

页面显示：
- 设计容量
- 满充容量
- 健康度百分比
- 循环次数

## 💡 使用技巧

### 1. 托盘后台运行

- 关闭窗口不会退出程序，会缩到托盘
- 右键托盘图标可重新打开或完全退出

### 2. 开机自启动

在 **设置** 页面可以设置：
- ✅ 开机自启动
- ✅ 启动时最小化到托盘

### 3. 快捷键

- `Fn + ↑`：切换风扇全速模式
- `Fn + F4`：切换触摸板开关

### 4. 诊断问题

如果遇到问题：
1. 点击 **关于** → **生成诊断报告**
2. 保存 ZIP 文件
3. 在 GitHub Issues 中反馈
